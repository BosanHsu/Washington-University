# Washington University Coursework

This repository contains coursework and group projects from the MSBA program at Washington University in St. Louis.

## Programming and Data Tools

### Intro to Python

Python homework, practice labs, and group projects. Topics include basic programming, pandas, data cleaning, merging, and data analysis.

### Intro to R

R homework, labs, and a final project covering programming, statistics, and data analysis.

### Database Design

SQL exercises using course, Lyft, and NBA data, along with submitted assignment reports.

### Cloud Computing

Coursework and a group project using Airbnb data. The files include data selection, PySpark analysis, a project report, and presentation slides.

## Business Research and Consulting

### Marketing Research

A market research project about Major League Soccer. The files include survey data, Python analysis, and a segmentation report.

### Student Consulting Project

A consulting project for the Bayless School District. The project reviews financial and student performance data and provides recommendations in an executive summary.

### Data Visualization

Tableau assignments and dashboards. The final group project studies NBA player performance, team performance, and team value.

## Machine Learning and Analytics

### Machine Learning

Individual and group assignments on machine learning methods in R. The files include R Markdown work and submitted reports.

### Text Mining

Labs on text normalization, classification, topic modeling, and sentiment analysis. The final project studies whether Twitter sentiment can help predict stock price movement.

### Prescriptive Analytics

Individual and group assignments using optimization methods, including PuLP and SciPy.

## Deep Learning and Reinforcement Learning

### Deep Learning

Course labs on business prediction tasks and a final project that uses LSTM models to match resumes with job descriptions.

### Deep Reinforcement Learning

Course labs on inventory management and a final group project that compares DQN, PPO, and A2C methods for Ethereum trading.
